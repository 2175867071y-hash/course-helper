# 网课助手 1.6.4（Windows）

[下载 Windows 程序和源码包](https://github.com/2175867071y-hash/course-helper/releases/tag/v1.6.4)。普通使用请下载 `.exe`；下方为使用说明和开发说明。

## 1.6.4 超星章节测验识别

双击 **网课助手-1.6.4.exe**。先停止旧版任务并退出，再用相同平台和课程名称添加任务。新版继续读取原有 API 设置和已保存密钥，无需重新输入。

本次只读检查了实际超星章节测验页。页面有三层嵌套课件，部分文字通过特殊字体显示，直接读取网页文字会得到错字。新版按已观察到的题干与选项区域截图，使用 Windows 本机中文文字识别，再把识别出的文字交给原有 AI 服务。此过程不需要新增 API Key，题目截图不上传；临时图片处理后删除。识别期间会显示当前题号。单次本机识别超时为 20 秒，点击停止后需等当前识别返回。

短选项用两种排版识别并比较结果；不一致或为空时提示手动核对。文字识别仍可能出错，结果一致不等于答案正确。题干或选项被滚动容器裁剪时会提示展开内容，避免只读取部分文字。如果电脑缺少简体中文文字识别组件，程序会提示安装后重试。

新版同时识别超星选项圆圈的选中样式，避免把选择状态文字当成选项内容；检查题目时排除表单外尚未显示的验证弹窗，提交后可读取同一测验容器内的成功提示。页面切换时，已知的课件加载异常最多重读三次，不重复点击或交卷。其他页面异常会记录出错模块和位置，方便后续定位。

本地测试使用模拟试卷和测试答案，实际课程只读取了页面结构，没有调用真实 AI 接口或提交答案。真实课程的完整答题流程及平台计分仍需使用时核对。

## 1.6.3 超星鼠标移出窗口后暂停

双击 **网课助手-1.6.3.exe**。先停止旧版任务并退出，再用相同平台和课程名称添加任务，保留“后台播放兼容”勾选。请在新版助手打开的浏览器中进入课程；旧版已打开的窗口不会自动应用新代码。原有 API 设置和已保存密钥继续使用。

本次查看实际课程页及其加载的播放器脚本，确认播放器在两层 iframe 中，却把鼠标移出事件绑定在最外层窗口。1.6.2 只处理播放器内部的离开事件，漏掉了这个情况。1.6.3 补充最外层窗口处理，仅用于超星学生学习页，并要求页面内仍有可见视频。页内鼠标移动及目录自身事件照常处理，手动暂停仍然有效。

本地复现测试中，旧逻辑会暂停；修复后，鼠标移出页面再最小化 Edge，视频按正常速度继续播放。真实课程目前只完成页面与脚本检查，尚未验证新版在该账号下的后台播放和平台计时结果。

## 1.6.2 后台播放兼容

双击 **网课助手-1.6.2.exe**。主界面默认勾选“后台播放兼容（切换软件 / 最小化）”。登录并进入课程后，点击“我已打开课程”，即可切换到其他软件或最小化课程浏览器。不要关闭浏览器；电脑仍需保持唤醒和联网。后台运行仍使用 CPU、内存和网络。

浏览器引擎已有页面活跃模拟和后台计时设置，本版补充网页事件兼容：拦截窗口失焦、页面隐藏通知，以及鼠标离开视频或已识别播放器容器的事件。输入框失焦和播放器内部移动照常处理，按钮点击与手动暂停仍然有效。兼容脚本在导航前注册，适用于新页面、刷新后的页面和嵌套课件。若运行记录提示已打开的课程页需刷新，请刷新该页后再开始。开关按本机设置保存，新任务使用新设置；取消勾选后，停止并重新添加任务即可回到普通模式。

该模式针对上述事件触发的暂停。使用其他检测方式的课程仍可能暂停，不能保证所有网站都能在后台连续播放。若播放器菜单或页面交互异常，可关闭该选项后重新启动任务。该选项不解决目录和题型识别问题，也不修改视频时间、播放速度或平台完成记录。实际 U校园课程的后台行为尚未联调验证。

本地对照测试使用真实 Edge 窗口最小化、原生鼠标操作和本地媒体：关闭兼容时，移开鼠标触发暂停；开启后，窗口保持最小化，媒体时间继续增长。输入框、暂停按钮及目录按钮另有回归检查。浏览器的 `hasFocus()` 在活跃模拟下不代表 Windows 前台状态，测试另外核对窗口确实保持最小化。

## 1.6.1 目录定位与焦点暂停处理

双击 **网课助手-1.6.1.exe**。先停止旧版任务并退出旧版，再用相同平台和课程名称启动；原有 API 设置、密钥及任务数据继续读取。

- 自动识别增加带“目录 / Contents / Course outline”等标题且有明确侧栏边界的自定义目录，要求同构可点击项目和唯一当前高亮项；支持带前后缀的 current、active、selected 样式名称，并保留侧栏中后续已展开的分组。
- 手动定位拦截鼠标按下、抬起及点击事件，避免网页先切换当前项；对于没有标准高亮标记的目录，可在用户明确指定当前项后记录其唯一底色或文字颜色，随目录规则保存。
- 网页顶部显示 0 / 2、1 / 2、2 / 2，区分未记录点击、只记录一次、跨页面区域点击、刷新丢失记录及目录结构不匹配。必须在助手为本任务打开的浏览器中定位。

此修复针对本地复现的目录结构与事件问题。尚未在截图中的真实课程页验证自动识别；没有可辨认高亮、未加载的折叠目录或未知课件结构仍会提示处理。不会把“视频结束”直接视为当前章节全部任务或整门课完成。

1.6.1 增加暂停恢复：视频普通暂停时读取浏览器报告的可见性和焦点；报告未聚焦时等待返回，再尝试恢复一次。它不会主动切换其他窗口，等待期间可用“停止所选”。浏览器的活跃模拟会影响这个检测，因此它不能单独判断 Windows 的前台窗口，也没有实现本版增加的事件兼容。媒体错误和异常进度仍提示检查。

1.6.0 增加图片输入、独立听力转写、可核验的 HTML 拖拽匹配与排序。设置分为“文字与图片”和“听力转写”，两组密钥均可在本机加密保存。材料不完整、图片变化、拖拽未被网页接受时暂停，不提交部分答案。

## 1.6.0 图片、听力与拖拽

1.6.0 起支持以下能力；从 1.5.3 及以后版本升级保留原密钥。设置保存后用于新启动的任务，运行中的任务需停止并重新添加。

- **图片**：“文字与图片”页保留文字模型和密钥，另有图片模型。官方地址 `https://api.deepseek.com` 的图片模型留空时使用 `deepseek-flash`；其他服务需填写其实际支持图片及 JSON 输出的模型。图片与文字共用地址和密钥。默认值依据 [DeepSeek 图片输入文档](https://api-docs.deepseek.com/guides/vision/)，不代表已经验证你的账户或代理服务。
- **听力**：“听力转写”页单独填写服务地址、转写模型和该服务的 API Key。需兼容 `/audio/transcriptions` multipart 接口，返回含 `text` 的 JSON；支持基础地址或完整转写地址。仅配置 DeepSeek 文字/图片服务还不能启用听力，不会自动复用另一服务的密钥。先转写再解题，协议参考 [语音转写文档](https://developers.openai.com/api/docs/guides/speech-to-text)。
- **拖拽**：支持有稳定选项编号、明确落点或排序容器的部分 HTML 控件。正常鼠标拖动后检查落点或顺序，再整卷复核；每个落点一个不同选项。图片选项还需图片模型。复制选项、虚拟列表、自由画布和未知控件可能仍需单独适配。
- **记住设置**：勾选“记住两组 API Key”，只需填写并保存一次。两组密钥分别使用 Windows 当前用户加密；取消勾选并保存会删除两组已保存密钥。

图片从明确题目或材料区的 img、SVG、canvas 采集；答题控件仍须能对应。图片中整张试卷、CSS 背景图片和未知图片交互尚不支持。单张最多 4 MiB，整组最多 24 张、12 MiB；材料变化会丢弃旧答案。

听力读取 audio 元素提供的完整文件，包括部分隐藏播放器。每段最多 20 MiB，整组最多 4 段、40 MiB，格式还须转写服务支持。分片流、受限音频、跨域读取失败、视频内听力、语调/音色/环境声音辨识及本人跟读录音尚不支持。失败时暂停，不只凭题干猜答案。

图片和题目文字发送至所配 AI 服务，音频发送至独立转写服务，转写文本再交给解题模型，会产生相应服务费用。媒体只在内存暂存，不写入进度记录或日志。共享媒体须属于明确材料区，账户卡片不会作为题目上传。“检测页面”只报告结构与媒体数量，不调用 AI 或下载媒体；发现媒体不等于已经适配其控件。

停止操作需要等待当前同步处理返回：单次 AI/转写请求超时 30 秒，音频读取超时 20 秒，多段音频与整卷复核可能需要更久。真实 U校园多媒体题、整课流程及 AI 正确率尚未端到端验证。

1.5.5 改进题目结构识别：支持表格左列题干/右列空格、有明确答题说明的编号段落和列表，以及 U校园已观察到的内嵌填空结构；保留表格标题、表头、共用题干、Directions 说明和多空顺序。个人自评显示识别题数、空格数和可读评分范围，需本人填写，不请求 AI 编造感受。检测页面新增题目诊断；修复带空格的“提 交”按钮匹配，并在 Task 切换后丢弃旧答案、隔离旧提交状态。

1.5.4 增加“通用课程（自动识别链接）”：填写 HTTPS 课程网址，已知平台沿用对应适配，其他站点尝试通用识别。新增按当前高亮项查找下一项、网页两点定位目录及保存、切页后的正文更新确认。正文未更新时暂停，不重复点击。静态阅读支持明确的 main/article 内容区域，长文章会滚动；文档“下一页”也需确认内容更新。

1.5.3 增加“记住 API Key”，默认开启。输入一次并保存后，使用 Windows 当前用户加密保护密钥，下次打开自动读取。取消勾选并保存可删除已保存的密钥；当前会话仍可继续使用。

1.5.2 修复 U校园从课程入口跳转到 `ucontent.unipus.cn` 课件后被误报“页面已离开所选课程平台”的问题，同时支持该地址的标签页选择、直接打开和视频进度恢复。

1.5.1 将主界面和自动学习设置中的复选框改为 Windows 原生勾号样式；选中表示开启，空框表示关闭。

支持在同一个窗口添加多门课程，同时运行超星学习通、中国大学 MOOC、U校园 AI 和通用课程任务。各任务使用独立浏览器、日志和进度提示，可单独停止。默认“整门课连续学习”，视频自然结束后继续切节；可识别文档自动翻页。AI 小测支持普通填空、多空、词库填空、完整文字阅读材料和同页混合题，可选自动提交或只填写。登录、验证码和无法识别的内容需人工处理。

用户已验证 1.1 的超星单个视频可以自然播放结束。1.5.5 已只读检查 U校园真实表格自评页的输入框、Directions、任务标签与容器结构，并据此复现本地测试；未填写或提交真实课程答案。**真实课程的解题、提交与整门课流程尚未端到端验证，不能保证任意课程都能全自动完成。**

## 双击版使用

双击 **网课助手-1.6.4.exe**，标题显示 1.6.4。先关闭旧版；原有视频记录继续使用。沿用各任务的独立登录目录；没有可用登录会话时需重新登录。从 1.5.3 及以后版本升级保留已保存的 API Key，无需重新输入。需要电脑已安装 Edge 或 Chrome，无需手动打开 PowerShell 或安装 Python。

1. 打开“自动学习设置”，填写 AI base URL、模型名称、API key，保持“记住 API Key”勾选，保存。设置用于随后启动的任务，运行中的任务保留启动时配置。
2. 选择“通用课程（自动识别链接）”或原有学习平台，给这门课填写固定、便于区分的课程名称，并粘贴课程链接。通用模式首次需要 HTTPS 链接；以后有视频记录时可留空恢复。
3. 保持“整门课连续学习”勾选，点击“添加并开始”。在新浏览器中登录、打开具体课程章节，再选中助手列表里对应任务，点“我已打开课程”。取消连续模式后才按本次视频数量限制。
4. 添加第二门课时，重新选择平台、课程名称和链接，再点“添加并开始”。其他任务会继续运行；同平台同名课程正在运行时不能重复启动。
5. 点击任务列表中的某一行，查看该任务的进度、日志及待处理提示。遇到无法处理的内容时，只暂停相关任务；在其浏览器中处理后点“已处理，继续”，必要时手动进入下一节。
6. “停止所选”只结束当前选中的任务，“全部停止”结束所有任务。到限或选择结束本课程后，浏览器先保留供核对，点击“关闭浏览器并返回”才关闭。

## 通用链接与目录翻页

“通用课程（自动识别链接）”接受使用标准 HTTPS 端口的课程网址，不再限于三个平台。打开具体课件后，自动识别超星、MOOC、U校园的已知地址，其他网站使用通用流程；未知站点运行中跨域跳转会提示确认并重新添加。首次切换到通用模式会使用该模式的独立任务登录资料，AI 设置仍共用。

有明确“下一节 / Next lesson”等按钮时优先使用；否则尝试语义化课程目录，以及同时具备明确目录标题和侧栏边界的自定义目录，按高亮项后面的项目切换。同名标题按目录位置区分。只改变高亮、正文或播放器未更新时不会认为切换成功，也不会重复点击。

自定义侧栏可在首次准备提示中选择“先定位目录”，或在待处理提示里点“定位目录”：

1. 在助手为本任务打开的浏览器中展开课程目录，确认网页顶部有“目录定位（0 / 2）”提示。
2. 依次点击目录中当前高亮的项目、紧接着的下一项；这两次点击用于定位。顶部计数依次变为 1 / 2、2 / 2，重复点击当前项不算第二项。
3. 顶部显示“目录定位（2 / 2）已完成”后，回到助手点“完成定位”。定位规则随该任务保存，下次自动读取；目录结构改变时可重新定位。

程序需要能识别当前高亮项，且两项在同一目录结构中。遇到下一项锁定、多个目录、折叠/虚拟列表未加载、当前展开目录末项时，会保留页面并提示处理；不会跳过锁定项或将目录末项直接当作整门课完成。手动进入新内容后点“已处理，继续”，程序仍检查正文是否更新。

通用入口不代表所有网站的内容都已适配。纯阅读页面需有明确内容区域；未知表单、画布、听力、口语等不会当作文档读完。任意 div 课件、图片题及特殊交互仍可能需要手动处理。网页能打开、AI 能生成答案，都不等于页面控件可可靠填写或平台已确认完成。

## U校园 AI

学习平台选择“U校园 AI”，在课程网址中粘贴自己的 `https://ucloud.unipus.cn/` 课程链接；也可留空打开平台首页。登录并进入具体课件后，再点击“我已打开课程”。不同平台的同名课程记录分别保存。

本版接受 `ucloud.unipus.cn`、`uai.unipus.cn`、课件主机 `ucontent.unipus.cn` 和统一登录主机 `sso.unipus.cn` 的 HTTPS 地址。仍在统一登录页时会提示先完成登录。U校园 AI 的[官方产品政策](https://app.unipus.cn/privacyUCloud/privacy.html)说明了口语、跟读等交互；这些不属于现有视频播放和文字选项识别的范围。

从课程入口跳到 `ucontent.unipus.cn` 后可继续识别平台，也可直接粘贴该课件地址。有多个课程标签页时，请选择具体课件。右侧目录可尝试上述“先定位目录”；`Quotation` 等静态引言页只有符合通用阅读结构时才会自动处理，实际课程尚未核实。遇未识别内容，请手动处理并进入下一项，再点“已处理，继续”。

**本版使用通用识别流程，尚未完成 U校园 AI 真实课程联调。** 支持已识别结构的文字题、词库和阅读题；新增图片、听力转写与拖拽的条件见开头。口语、分页试卷、个人自评和缺少必要材料或未知控件的题目仍需手动处理。处理后点击“已处理，继续”，必要时手动进入下一节。截图只能说明题目内容，不能证明真实网页的填写控件已适配。

## 自动学习设置

- 文档：默认每页/屏停留 10 秒，可设 3 到 120 秒，需要有可识别翻页按钮或滚动区域。任务点完成以平台显示为准。
- 小测：已知平台和通用课程都尝试识别内容完整的文字选择题、填空、多空、原生下拉、共享词库和阅读材料。同页可混合不同题型。词库支持 AI 按题意变换词形、拆分短语；明示每词限用一次时检查跨题重复。无法确认完整材料、题目范围或输入位置时提示人工处理，不提交部分试卷。
- 表格与内嵌空格：按题干与控件共同分组，表格中的多个空格保持顺序，表头与前置共用说明一起读取。只认明确答题区，普通账户信息表格、目录搜索不作为题目。隐藏空格、隐藏说明或未知答题控件会提示处理。
- 个人自评：例如“Your score / 1 = Strongly disagree / 7 = Strongly agree”，显示已识别的题数和空格数、评分范围；即使未配置 AI，也优先说明这是本人评分。请自己填写并提交，手动进入下一 Task，再点“已处理，继续”。本版不会自动填写个人感受，也没有新增 Task 自动跳转。
- 检测页面：日志显示识别到的题数、空格数，以及可处理/需要人工处理的原因。检测不调用 AI、不填写答案，报告不包含题干或已填答案。
- 提交模式：默认勾选“自动提交小测”。关闭后只填写并核对，在浏览器检查和手动提交后，回到助手点“已处理，继续”。等待期间不重复请求 AI。自动模式也会在填写后重新检查完整题目和全部答案，再提交并等待本测验新出现的成功提示，结果不确定不会重复交卷。个人自评或要求描述本人经历的题目需要你填写。
- 接口：需要 HTTPS 的标准 Chat Completions 兼容服务地址，例如服务商给出的 `https://服务地址/v1`，也可填完整 `/chat/completions` 地址；模型需要支持 JSON 输出。
- 数据：解题需要的题干、选项、词库、题目说明和阅读材料会发送至配置的服务，不发送登录信息。API 可能计费，AI 可能错答；自报置信度低于 0.85、缺题、缺空或无效选项时不提交。置信度与格式检查都不是正确性保证。整组材料过长会明确提示，不静默截断。
- 密钥：“记住 API Key”默认开启，保存后用 Windows DPAPI 当前用户加密，只有密文写入本机 `settings.json`，日志不记录密钥。下次启动会自动读取，输入框保持遮挡。取消勾选并保存会删除密文，密钥仅保留在本次会话；清空输入框并保存也会移除密文。地址与模型名继续保留。保存设置不会发起网络请求。
- 从 1.5.2 或更早版本升级需再输入并保存一次，因为这些版本没有保存密钥；从 1.5.3 升级继续读取已保存密钥。加密数据依赖 Windows 用户环境，换电脑或账号后可能需要重新填写；读取失败会在界面提示，不影响打开软件。保存失败时保留旧设置和未保存草稿，不会退回明文保存。
- 并行任务：每个任务保留启动时的自动学习设置和 AI 配置；修改设置只影响之后启动的任务。要让运行中的任务使用新配置，请先停止该任务，再重新添加。

未配置 AI 不影响视频学习，遇小测会提示配置或人工答题。软件不改倍速、不跳进度、不修改平台完成状态。

## 记录与恢复

使用相同平台和课程名称、网址留空，恢复最后记录的视频章节；恢复时间由平台控制。不同课程使用不同名称。文档和小测目前不单独写入视频观测记录。

设置、日志、登录资料和视频记录保存在 `%LOCALAPPDATA%/CourseHelper`。每个任务的日志、检测报告及浏览器登录目录分别保存，视频记录仍共用原有数据库。多任务请在同一个助手窗口中添加，不要另外启动多个助手实例。停止时需等待同步处理返回；单次 AI/转写超时 30 秒，多段音频处理可能更久。运行时保持电脑唤醒、网络连接和各浏览器窗口可用。

图形版数据位置：共用视频记录为 `progress.sqlite3`；每个任务位于 `tasks/<任务标识哈希>/`，其中保存 `helper.log`、`inspect.json`、目录定位规则 `navigation.json` 及 `profile-msedge` 或 `profile-chrome`。标识由平台和课程名称生成，不把课程名称直接用作文件夹名。旧版登录目录保留，但不会复制到这些并行任务目录。

源代码图形入口为 `gui.py`。以下命令行入口仍以视频辅助为主，AI 和文档设置请用图形版；使用 exe 无需执行命令。

## 1. 安装前提

需要 Windows、Python 3.10 或更新版本（含 `py` 启动器和 pip），以及 Microsoft Edge。先在本文件所在文件夹打开 PowerShell：

```powershell
py -3 --version
py -m pip install -r requirements.txt
```

如果提示找不到 `py`，先安装 Windows 版 Python 并启用启动器，然后重新打开 PowerShell。若有多个 Python 环境，请使用 `py -3 -m pip install -r requirements.txt`，让安装与下面的启动命令使用同一环境。

程序默认通过 `msedge` 使用本机 Edge。它另建 `data/profile-msedge`，首次需要手动登录；不会继承日常 Edge 的登录状态。同一个助手 profile 不要同时启动两个实例。Playwright 的浏览器通道说明见[官方浏览器文档](https://playwright.dev/python/docs/browsers)，独立持久化目录说明见 [BrowserType 文档](https://playwright.dev/python/docs/api/class-browsertype#browser-type-launch-persistent-context)。

## 2. 先检测，再运行

可用 `start.ps1` 菜单选择“检查依赖”“inspect 超星”“run 超星”或“status”。打开菜单本身不会安装依赖或开始播放：

```powershell
.\start.ps1
```

如果本机策略不允许 PowerShell 脚本，直接使用下面的 Python 命令即可。

**先检测页面：**

```powershell
py -3 -X utf8 main.py inspect --platform chaoxing
```

在弹出的独立 Edge 中登录，打开具体的视频章节，再回终端按 Enter。如打开了多个平台标签页，按提示选择对应页面。检查终端报告及 `data/inspect.json`：应识别到目标视频；`guard` 应为 `null`；需要自动切节时，`has_next` 应为 `true`。`inspect` 不主动播放或点击下一节，但课程页面本身可能自动播放。

**页面识别符合预期后，再运行：**

```powershell
py -3 -X utf8 main.py run --platform chaoxing --task-id my-course --max-chapters 30
```

同样先在浏览器打开目标章节，再回终端按 Enter。助手会尝试正常播放，观察进度并在自然结束后切换章节。运行时保持电脑唤醒、网络连接和浏览器窗口可用。`--max-chapters` 限制本次观察到的视频结束数量，默认 0 表示不限，允许 0 到 1000。

遇到需人工处理的情况，先处理浏览器页面，再回终端输入：

- `r`：继续当前任务。
- `s`：结束当前任务；如果使用任务文件，则继续下一个任务。
- `q`：退出全部任务。

也可按 `Ctrl+C` 退出。退出时程序会尽力暂停视频，进度保留到最后一次观测。

## 3. 恢复章节与查看记录

为每门课程选择不同且固定的 `--task-id`，下次使用同一个 ID：

```powershell
py -3 -X utf8 main.py run --platform chaoxing --task-id my-course --resume
py -3 -X utf8 main.py status
```

`--resume` **只恢复最后记录的章节网址**。视频播放位置由平台恢复，助手不会按本地秒数跳转；登录过期或旧链接失效时，需手动重新打开章节。未指定 ID 时程序会生成并显示一个 ID，可保存供下次使用。

`status` 显示本地观测值；`video_ended` 只表示本次观察到了视频自然结束。**本地记录或观察结束不等于平台确认完成、获得学分或课程达标，最终以平台页面为准。** 超星仍显示任务点未完成时，程序会停下来要求人工确认。

## 4. 任务文件与 MOOC

复制 `tasks.example.json` 为 `tasks.json`，为每项设置唯一固定的 `id`，把示例首页 `url` 替换为你实际课程的 HTTPS 视频章节地址；删除不需要的示例任务。任务依次运行，每项仍需你确认页面。

```powershell
py -3 -X utf8 main.py run --tasks tasks.json
py -3 -X utf8 main.py run --tasks tasks.json --resume
```

任务文件支持 `platform`（`chaoxing` / `mooc` / `uai`）、`url`、`max_chapters`，以及可选的 `video_selector`、`next_selector`（精确 CSS 选择器）。`--tasks` 不与 `--url` 或 `--task-id` 同用。超星/MOOC 仅支持对应平台的 `chaoxing.com` / `icourse163.org` 域名及子域名；U校园 AI 仅接受上面列出的四个主机。

MOOC 请先单独检测；通用按钮识别可能不适用于你的课程，不能保证自动切节：

```powershell
py -3 -X utf8 main.py inspect --platform mooc
py -3 -X utf8 main.py run --platform mooc --task-id my-mooc-course
```

## 5. 常见情况与本地数据

- **浏览器启动失败：**关闭本助手的其他实例，确认 Edge 已安装。也可使用已安装的 Chrome，加 `--channel chrome`。如明确要使用 Playwright 的 Chromium，先执行 `py -3 -m playwright install chromium`，再加 `--channel chromium`；此操作会下载浏览器，菜单不会自动执行。
- **找不到视频或识别到多个视频：**打开具体视频章节，关闭其他播放器，重新 `inspect`；必要时在任务文件配置精确选择器。
- **下一节、登录、测验或验证码阻断：**按终端提示手动处理；没有下一节且课程已经结束时，输入 `s`。
- **已尝试点击下一节但切换超时：**程序不会重复点击同一节。请在浏览器中手动切到目标新章节，再按 `r`。
- **页面规则改变或媒体错误：**先停止助手，核对页面；保留检测报告用于排查，不能把本地记录当作课程完成凭证。

运行后生成的 `data/` 包含浏览器 profile、登录会话、带课程网址的 SQLite 观测记录、检测报告和日志。**不要分享整个 `data/` 文件夹或登录会话。** 如需分享诊断内容，先检查并去除个人信息。删除 `data/` 会丢失助手登录状态及本地恢复记录。

全部命令选项：`py -3 -X utf8 main.py --help`。
