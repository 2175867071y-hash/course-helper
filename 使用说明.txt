网课助手 1.6.4 · 双击使用

先停止旧版任务并退出，双击“网课助手-1.6.4.exe”。无需手动打开 PowerShell 或安装 Python。
电脑需已安装 Microsoft Edge 或 Google Chrome。
从 1.5.3 及以后版本升级继续读取原有密钥、课程记录和各任务登录目录。

1.6.4 改进超星章节测验页的识别。
特殊字体题干与选项使用 Windows 本机中文文字识别，再交给原有 AI 服务。
无需新增密钥；截图在本机处理后删除，识别出的题目文字会发送至所配 AI 服务。
短选项的两次识别结果不一致，或内容被滚动区域裁剪时，会提示核对。
识别期间显示当前题号，单次超时 20 秒；停止操作需等当前识别返回。
缺少中文文字识别组件的电脑会提示安装。文字识别和 AI 答案均可能出错。
同时修复选项状态判断及表单外提交结果识别，切换课件时短暂重读页面。
实际课程只完成页面结构检查，未提交真实答案；本地使用模拟试卷验证。

1.6.3 修复超星双层课件中，鼠标离开最外层窗口仍触发暂停的问题。
保持“后台播放兼容”勾选，在新版助手打开的浏览器中进入课程并开始任务。
旧版已打开的课程窗口不会自动应用新代码。
本地复现与最小化播放对照测试已通过；真实课程完成了页面和脚本检查，
尚未验证新版在该账号下的后台播放和平台计时结果。

1.6.1 修复目录定位：支持有明确侧栏边界和目录标题的自定义目录，要求可点击项目和唯一高亮项；
支持带前后缀的当前项样式，保留后续已展开分组；手动定位可记录唯一高亮颜色。
定位时网页顶部显示点击计数，失败原因更具体。真实截图课程尚未联调验证。

1.6.2 默认勾选“后台播放兼容（切换软件 / 最小化）”。
登录、进入课件并点击“我已打开课程”后，可切换软件或最小化课程浏览器。
若运行记录提示已打开的课程页需刷新，请刷新该页后再开始。
兼容窗口失焦、页面隐藏，以及鼠标离开视频或已识别播放器容器导致的暂停。
电脑需保持唤醒和联网；不要关闭课程浏览器。后台仍消耗 CPU、内存和网络。
本地最小化播放对照测试已通过；实际 U校园课程尚未验证，其他暂停检测仍可能不兼容。
页面或播放器交互异常时，可取消勾选，停止并重新添加任务。开关会自动保存。
目录和题型识别仍按原有规则；后台播放兼容不修改播放时间或平台完成记录。

保留 1.6.0 的图片题、听力转写、部分 HTML 拖拽匹配和排序。
不是任何网站和控件都已适配，无法确认完整题目或操作结果时仍会暂停。

你使用 DeepSeek 时

1. 打开“自动学习设置”→“文字与图片”。原地址、文字模型和密钥会保留。
2. 如果地址是 https://api.deepseek.com，图片模型留空会使用 deepseek-flash。
   第三方代理需填写该服务实际支持图片和 JSON 输出的模型名称。
   图片与文字共用地址和密钥，不需要再复制一遍密钥。
3. 听力需在“听力转写”另外填写转写服务地址、转写模型和该服务的 API Key。
   服务需兼容 /audio/transcriptions 接口。仅配置 DeepSeek 文字/图片还不能转写听力。
   程序不会把 DeepSeek 密钥自动发给另一个服务。
4. 保持“记住两组 API Key”勾选并保存，下次打开自动读取。
5. 配置用于新任务；正在运行的课程请先停止，再重新添加。

支持范围

图片：明确题目和材料区中的图片、SVG、画布；选择或填空控件仍需能对应。
单张最多 4 MiB，整组最多 24 张、12 MiB。图片变化会丢弃旧答案。
图片中整张试卷、CSS 背景图及未知交互控件暂未适配。

听力：读取页面 audio 元素的完整音频，先转写再结合题目解答。
每段最多 20 MiB，整组最多 4 段、40 MiB，格式还需转写服务支持。
分片流、受限音频、跨域读取失败、视频内听力、语调/音色辨识及本人录音暂不支持。
读取或转写失败会暂停，不只凭题干猜答案。

拖拽：支持有稳定选项编号、明确落点或排序区域的部分 HTML 控件。
每个落点一个不同选项；完成后检查落点和顺序，再整卷复核并提交。
图片拖拽需图片模型。复制选项、自由画布、复杂自定义控件可能需单独适配。

图片、题干和选项发送到所配 AI 服务；音频发送到独立转写服务，
转写文字再交给解题模型，可能产生 API 费用。AI 可能答错。
媒体暂存内存，不写入进度和日志。检测页面只报告结构与媒体数量，不调用 AI。
“自动提交小测”默认开启，关闭后只填写，等待你检查和手动提交。
登录、验证码、个人自评、本人经历及口语录音仍需你处理。

课程链接与多课程并行

1. 选“通用课程（自动识别链接）”或原有平台，填写固定课程名称和 HTTPS 课程链接。
2. 勾选“整门课连续学习”，点“添加并开始”，在新浏览器登录并进入具体课件。
3. 回助手选中任务，点“我已打开课程”。
4. 目录无法识别时点“先定位目录”，在助手为本任务打开的浏览器中，
   确认顶部出现“目录定位（0 / 2）”，再依次点当前高亮项和紧接着的下一项。
   顶部显示“2 / 2 已完成”后回助手点“完成定位”。定位规则按任务保存。
5. 添加第二门课时重新选平台、名称和链接，再点“添加并开始”，前一门会继续。

同平台同名课程运行时不可重复添加，不同课程请用不同名称。
任务列表选一行查看其日志；“停止所选”只停止该任务，“全部停止”结束所有任务。
切节需确认正文或播放器更新，不会重复点击。未知网站跨域会提示重新添加。
目录末项、锁定内容或未展开目录会提示核对，不直接认定整门课完成。
本版没有新增 U校园 Task 自动切换，未知结构仍可能需要手动进入下一项。

停止、恢复与密钥

到达视频限制或选择“结束本课程”后，浏览器先保留供核对。
停止任务会关闭对应助手浏览器。网络操作中停止需等待同步操作返回；
单次 AI/转写请求超时 30 秒，音频读取超时 20 秒，多段音频可能需要更久。
运行时保持电脑唤醒、网络和浏览器窗口可用。

下次用相同平台和名称，网址留空可恢复最后记录的视频章节；播放位置由平台恢复。
文档和小测不单独保存为视频记录。数据位于 %LOCALAPPDATA%/CourseHelper。
多任务在同一个助手窗口添加，不要启动多个助手实例。
密钥使用 Windows 当前用户加密；取消“记住”并保存会清除两组已保存密钥。
换电脑或 Windows 账号可能需重新填写。保存失败不会改为明文存储。
